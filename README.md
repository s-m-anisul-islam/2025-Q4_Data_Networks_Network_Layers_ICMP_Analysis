# Network Layers and ICMP Analysis

## Overview
Hands-on exploration of network layered architecture, data encapsulation, and ICMP traffic analysis.

## Tools Used
- Cisco Packet Tracer (.pkt)
- Wireshark (.pcap)

## Key Learnings
- Observed TCP three-way handshake and Ethernet frame details
- Identified source and destination IP and MAC addresses
- Analyzed ICMP traffic for end-to-end vs next-hop addressing
